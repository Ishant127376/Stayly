# Stayly 🏡

A full-stack vacation rental booking platform inspired by Airbnb, built with Next.js, FastAPI, and PostgreSQL.

## ✨ Features

- User authentication and session management
- Destination autocomplete and property search
- Property listings and detail pages
- Reservation workflow
- Booking confirmation email functionality

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Python, FastAPI
- **Database & ORM:** Neon PostgreSQL, SQLAlchemy
- **Deployment:** Vercel, Render
